## Grid / layout method (new — see method/03-space-grid.md for the integrated version)

The grid is tokenized, breakpoint-first, and inherits the global spacing cadence. See the
methodology for the full portable principles; in brief: breakpoint is the top grid axis, each tier
owns a complete independent grid; gutter is tokenized per (breakpoint × column-count); margins and
gutters draw from the shared spacing scale; device-margin, container-inset, and section-spacing are
three independent responsive padding families; container max-width is capped and breakpoint-scoped,
with margin collapsing toward zero (edge-to-edge) on small tiers.
