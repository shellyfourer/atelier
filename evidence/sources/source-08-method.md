# Source Method — Source08 (playful party/games retail storefront; explicit desktop + mobile breakpoint frames)

A high-chroma, multi-category commerce store authored at two breakpoints with full per-breakpoint style-guide artboards. Its teaching value is that it takes several methods the library already held as *flat* ideas and shows them as *structured* ones: category color becomes a two-token pair, typography becomes a three-face role partition, "variants" collapse to one themed atom, composition gains angled/stacked primitives, and the page catalogue splits into four tracks (pages / overlays / states / responsive rule). Register here is loud — and the source demonstrates the discipline of quarantining that loudness to a single swappable layer.

## What this source teaches (teacher, not template)

**Color — the four-layer split, with category as a pair and a scope function.**
Build color in four independent layers, each with one job: (1) a neutral tonal ramp as the structural spine; (2) one brand constant locked to global chrome (header/footer/persistent bands), exposed via a semantic token not a raw hex; (3) a category accent layer; (4) a thin semantic set (success/error/interaction). The new teaching is in layer 3: mint each category not as a lone hue but as a **two-token pair {saturated accent, matched pale tint of the same hue}** — accent drives interactive/active surfaces, tint drives calm backing surfaces. The pair behaves as a **swappable theme channel selected by scope**: a category in scope re-themes the whole content region to its pair; chrome stays brand; *nothing in scope* ('All' view, global filter sheet) falls back to the brand primary. Bind the accent at the **smallest meaningful unit (the card/item)** so a mixed list self-themes into an at-a-glance taxonomy legend, while a filtered page collapses to a single theme — one mechanism, two legibility jobs, chosen by composition density. Register dial: tune **only** the category layer's chroma to the brand register; keep ramp, type, and chrome constant so loudness never destabilizes structure.

**Typography — role x size x breakpoint, plus typeface as a third semantic axis.**
Composite role tokens (family+size+weight+lineHeight+letterSpacing bundled) remain the unit. New: **typeface assignment is itself a role-class signal** — up to three purposeful faces, one owning the monotonic heading ramp, one owning reading body + small support, one reserved for interactive/navigational roles (links, buttons, footer utility). **Interactive roles get their own mid-size band** that may overlap heading sizes numerically but stays a 'control' token via its family+medium weight — so size alone never determines role. Tokens are named by **role/intent, not resolved value**, so two roles with identical current metrics stay separate and can diverge later. Responsive = **swap a breakpoint-suffixed named composite variant**, never fluid-scale a single property.

**Component architecture — collapse N looks to one themed atom.**
When a design shows N visually-distinct cards/sections, find the invariant skeleton and externalize the per-instance delta to a **single category/data token binding** (the {accent, tint} pair) instead of authoring N parallel components — component count stays flat as categories grow. Keep three separated surfaces: a token/foundation sheet, a true-component library of reusable main symbols, and composed layout sections/page skeletons. Model responsive sizing as **one semantic role name resolving to breakpoint-specific values** — never fork a component to change sizes. Promote desktop-inline affordances (filter rail, mini-cart, gate, auth) into standalone mobile **overlay/sheet surfaces** that are themselves first-class library entries.

**Page composition — bands, not a stack; plus four new primitives.**
Drive feeling through **density oscillation** (airy↔dense↔compressed band to band) and **grid-break-as-narrowing** (drop from the multi-column grid to a single asymmetric focal split to signal emphasis). New compositional vocabulary: (1) **diagonal seam** — split a section with a slanted color-block edge and let the focal cluster straddle it; (2) **stacked-deck fan** — arrange a set of peer cards as one overlapping, slightly-rotated object; (3) **tilted divider planes** — separate sections with subtly skewed sheets so the page reads as overlapping planes; (4) **interstitial reset band** — a short full-bleed saturated band as a palette-cleanser between white sections, whose structural role (reset the rhythm) is independent of its content. Proof is **threaded** (mid-page band + ratings in cards + footer reviews), never concentrated once.

**Page anatomy — a four-track catalogue.**
Track 1, full-page skeletons (persistent header → ordered body → persistent footer, each section tagged required/recommended/optional). Track 2, **overlay skeletons** catalogued separately, each tagged with the breakpoint(s) it appears on and the inline region it replaces. Track 3, **state variants** — budget empty/zero/error/gate states as their own section stacks, not just the happy path. Track 4, the **responsive rule**: section ORDER is breakpoint-invariant; below the breakpoint, reflow multi-column→single-column AND promote selected inline regions to overlays. Within this: **checkout is a stepped flow family** (details→shipping→payment→review→confirmation) sharing one persistent order-summary slot (desktop right rail / mobile top accordion); **PLP is one skeleton parametrized by taxonomy**, not N near-identical siblings; **blog is a two-skeleton pair** (index grid ↔ article with author/taxonomy/popular/related sidebar); a **compliance/age/consent gate** is a chrome-less binary frame, first in the journey.

## Register note
This is a *loud* source. Its discipline lesson is that the architecture is register-agnostic: the same four-layer color model, three-face type model, and four-track page catalogue serve a clinical/premium client and a party client alike — only the category-layer chroma is re-dialed. Do not read the hot-pink/electric-blue palette as the method; the method is the quarantine.
